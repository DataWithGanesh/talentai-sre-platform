# TalentAI - Production Grade AI Hiring Platform

## Overview

TalentAI is an AI-Native Hiring Platform designed using modern SRE principles.

The platform enables:

- Candidate Registration
- Resume Upload
- AI Resume Screening
- Interview Scheduling
- Notification Management
- Recruiter Dashboard
- Hiring Manager Dashboard

---

## Business Goal

Reduce manual hiring effort using AI-powered automation.
